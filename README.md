# Rounit Kumar — Portfolio

A premium dark editorial portfolio built with plain HTML, CSS, and JavaScript. No build step or framework is required.

## Files

- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design and layout
- `script.js` — mobile navigation and current footer year
- `RounitKumar_Resume.pdf` — resume download
- `assets/` — optional additional images and assets

## Keep Your Existing Live URL

Updating the source code does not require changing your existing domain or hosting configuration. Push the updated files to the same GitHub repository and ensure your hosting service continues deploying from the correct branch and folder.

## Before Publishing

1. Confirm that your profile image exists at the path referenced in `index.html`.
2. Confirm that the resume link points to the correct filename: `Rounit_Kumar_Resume.pdf` or `RounitKumar_Resume.pdf`, whichever your HTML actually uses.
3. Verify that project links point to the correct GitHub repositories and live demos.
4. Preview the portfolio on mobile and desktop.
5. Confirm that your hosting service successfully deploys the updated files.

## Local Preview

Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

After resolving conflicts, push the updated code to the `main` branch. If GitHub Pages is configured to deploy from that branch and folder, it will publish the changes to your existing site.
